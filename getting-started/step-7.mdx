Navigate to `https://app.yoursite.com` in your browser.

You should see the FrankPHP sign-in screen, asking for your email address.

<Check>
If you see the sign-in screen, FrankPHP is installed correctly. Everything worked.
</Check>

If you see a blank page or a PHP error, the most common causes are:

- `.env` has incorrect database credentials
- The subdomain is pointing to `/yourproject/app` instead of `/yourproject/app/public`
- Your database user doesn't have permission to create tables (needed for the automatic first-boot schema setup)
- File permissions — your host may require folders to be `755` and files `644`
- The web server can't create `app/private/sessions`, the folder FrankPHP keeps sign-in sessions in
- A required setting in `app/.env` is missing or empty — FrankPHP stops with a message naming it. See [Environment Configuration](/architecture/environment-configuration#every-key)
